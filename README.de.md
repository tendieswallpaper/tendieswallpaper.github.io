## 💡 Was ist eine `.tendies`-Datei?

Eine **`.tendies`-Datei** ist ein spezielles Wallpaper-Paketformat für das Nugget / PosterBoard-System.

Statt batteriefressender Hintergrund-Apps oder 3-Sekunden-Live-Fotos integrieren sich `.tendies`-Dateien direkt in den nativen **PosterBoard**-Container von Apple:
1. **Container-Assets**: Native Plists werden ohne Modifikation von Systempartitionen eingespielt.
2. **Eindeutige UUIDs**: Verhindert Konflikte bei mehreren installierten Hintergrundbildern.
3. **0% Akkuverbrauch im Standby**: Hardware-beschleunigtes Rendering direkt durch iOS mit flüssigen **60 FPS**.

## 🚀 Installation in 4 einfachen Schritten

1. **Datei herunterladen**: Wählen Sie Ihr Lieblings-Wallpaper im [offiziellen Store](https://tendieswallpaper.com/) und laden Sie die `.tendies`-Datei.
2. **Gerät anschließen**: Schließen Sie Ihr iPhone oder iPad per USB-Kabel an den PC oder Mac an und tippen Sie auf **„Diesem Computer vertrauen“**.
3. **In Nugget anwenden**: Öffnen Sie Nugget, gehen Sie zu **PosterBoard**, wählen Sie die Datei und klicken Sie auf **Apply Changes**.
4. **Neustarten und auswählen**: Nach dem Neustart halten Sie den Sperrbildschirm gedrückt und wählen Sie das neue Hintergrundbild unter Sammlungen aus.

> 📖 **Ausführliche Anleitung:** [Nugget PosterBoard Installationshandbuch](https://nugget.host/en/tutorial/nugget)
