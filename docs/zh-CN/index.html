The .tendies file

什么是 tendies 文件？

.tendies 文件 是整个 Nugget / PosterBoard 生态（包括 Cowabunga 和 Pocket Poster）使用的壁纸包格式。它保存了 Nugget 会还原到设备上的 PosterBoard 文件结构，让壁纸直接显示在原生锁屏壁纸选择器中。

📱

Container format · posterboard

直接还原到 PosterBoard 应用容器，保持原有文件结构与壁纸 ID 不变。

📁

Descriptor format · descriptors

还原到壁纸描述符文件夹，UUID 随机化，多张 tendies 壁纸互不冲突。

🎬

Extra variants · suggested / mercury

视频和照片变体适用于建议照片；mercury 变体适用于支持的 iOS 版本上的 Mercury Poster。

FAQ

常见问题

开始之前，你需要了解的 tendies 壁纸一切信息。

什么是 tendies 壁纸？+

tendies 壁纸是专为 iPhone 和 iPad 设计的动态动画壁纸，以 .tendies 文件形式交付，通过 Nugget 工具安装。tendies 文件会将 PosterBoard 壁纸描述符还原到 iOS 17-26 设备，使壁纸显示在锁屏的“合集”选择器中。

什么是 .tendies 文件？+

.tendies 文件是 Nugget 和 Pocket Poster 使用的壁纸包格式。它保存了还原到 iPhone 或 iPad 的 PosterBoard 文件结构，也是安装自定义动态锁屏壁纸时需要导入的文件。

tendies 壁纸需要越狱吗？+

不需要。tendies 壁纸通过开源工具 Nugget 安装，Nugget 使用 Apple 自有的 SparseRestore 与 BookRestore 机制安全修改文件，无需越狱。

哪些 iOS 版本支持 tendies 壁纸？+

tendies 壁纸在兼容的 iPhone 和 iPad 上支持 iOS 与 iPadOS 17–26。部分壁纸可能要求特定 iOS 版本，请始终查看壁纸页面上的兼容性说明。

在哪里可以下载 tendies 壁纸？+

前往 mwallx.com 的 Nugget Wallpaper 壁纸库浏览并下载 tendies 壁纸，这里收录了动漫、体育、漫威等多种精选动态与静态壁纸。

如何在 iPhone 上安装 tendies 壁纸？+

下载 .tendies 文件，在 Nugget 中打开 PosterBoard 功能，选择文件，应用更改并重启设备。重启后在锁屏编辑器里，在“合集”或“收藏”中找到新壁纸。

使用 tendies 壁纸安全吗？+

Nugget 是广受欢迎的开源项目，拥有数千名用户。与任何系统修改一样，请先备份设备。所有更改均可通过 iTunes 或 Finder 还原设备来撤消。

Nugget Wallpaper 与 tendies 壁纸有什么区别？+

Tendies Wallpaper 是动态壁纸合集的品牌名，而 Nugget Wallpaper（mwallx.com）是承载它们的壁纸库。两者同属一个生态，由用于 iOS 自定义的开源工具 Nugget 驱动。
