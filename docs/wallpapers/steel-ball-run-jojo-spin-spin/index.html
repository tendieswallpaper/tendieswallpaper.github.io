Step-by-Step Guide

How to Install Steel Ball Run — Spin Spin

Applied using Apple's SparseRestore protocol via the free Nugget tool. Takes under 3 minutes.

01

Get the .tendies file

Download the dynamic wallpaper bundle package from the official repository.

02

Connect your iPhone / iPad

Plug your device into your computer (macOS/Windows) via USB and confirm "Trust This Computer".

03

Import in Nugget

Open Nugget, select PosterBoard → Import .tendies file, then click "Apply Changes".

04

Reboot & Select

After your device restarts, long-press your lock screen and find this wallpaper under Collections.
