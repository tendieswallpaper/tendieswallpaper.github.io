The .tendies file

What is a tendies file?

A .tendies file is the wallpaper bundle format used across the Nugget / PosterBoard ecosystem (including Cowabunga and Pocket Poster). It stores the exact PosterBoard file structure that Nugget restores onto your device, so the wallpaper shows up right inside the native lock-screen wallpaper picker.

📱

Container format · posterboard

Restores directly to the PosterBoard app container, keeping the exact file structure and wallpaper IDs untouched.

📁

Descriptor format · descriptors

Restores to the wallpaper descriptors folder with randomized UUIDs so multiple tendies wallpapers never conflict.

🎬

Extra variants · suggested / mercury

Video and photo variants target Suggested Photos; mercury variants target the Mercury Poster on supported iOS versions.

Getting started

Install a tendies wallpaper in 4 steps

The entire process takes a few minutes with a USB cable and the free Nugget app. Full details are in the official tutorial.

01

Download the file

Pick a wallpaper from the library and download its .tendies file.

02

Connect your device

Plug your iPhone/iPad into your computer via USB and trust it. Works on Windows, macOS and Linux.

03

Import & apply

Open PosterBoard inside Nugget, select the file, then hit Apply Changes.

04

Reboot & enjoy

After reboot, open the lock-screen editor and find your new wallpaper under Collections or Favorites.

FAQ

Frequently asked questions

Everything you need to know about tendies wallpapers before you get started.

What is a tendies wallpaper?+

A tendies wallpaper is a dynamic, animated wallpaper for iPhone and iPad, shipped as a .tendies file that is installed through the Nugget tool. Tendies files restore PosterBoard wallpaper descriptors onto iOS 17-26 devices so the wallpaper appears in the lock-screen Collections picker.

What is a .tendies file?+

A .tendies file is the wallpaper bundle format used by Nugget and Pocket Poster. It stores the PosterBoard file structure that gets restored to your iPhone or iPad, and it is what you import when you want to install a custom dynamic lock-screen wallpaper.

Do tendies wallpapers require a jailbreak?+

No. Tendies wallpapers are applied with the open-source Nugget tool, which uses Apple's own SparseRestore and BookRestore mechanisms to modify files safely, no jailbreak is required.

Which iOS versions support tendies wallpapers?+

Tendies wallpapers support iOS and iPadOS 17 through 26 on compatible iPhones and iPads. Some wallpapers may require a specific iOS version, so always check the wallpaper page for compatibility notes.

Where can I download tendies wallpapers?+

Browse and download tendies wallpapers from the Nugget Wallpaper library at mwallx.com, which hosts a curated collection of dynamic and static wallpapers including anime, sports, Marvel and more.

How do I install a tendies wallpaper on my iPhone?+

Download the .tendies file, open the PosterBoard feature inside Nugget, select the file, apply changes, and reboot your device. After rebooting, open the lock-screen wallpaper editor and find the new wallpaper under Collections or Favorites.

Is using tendies wallpapers safe?+

Nugget is a widely used open-source project with thousands of users. As with any system modification, back up your device first. Changes are reversible by restoring your device through iTunes or Finder.

What is the difference between Nugget Wallpaper and tendies wallpaper?+

Tendies Wallpaper is the brand name for the collection of dynamic wallpapers, while Nugget Wallpaper (mwallx.com) is the library that hosts them. Both are part of the same ecosystem, powered by the open-source Nugget tool for iOS customization.
