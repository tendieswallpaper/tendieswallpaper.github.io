## 💡 `.tendies` ファイルとは？

**`.tendies` ファイル** は、iOSカスタマイズツール Nugget / PosterBoard 用に設計された壁紙バンドル形式です。

バッテリーを消耗するサードパーティの動画アプリや3秒制限のLive Photosとは異なり、Apple純正の **PosterBoard** コンテナへ直接展開されます：
1. **ネイティブ統合**: システムのルート領域を変更することなく安全にインポート。
2. **UUID分離**: ランダムなUUID生成により、複数の動的壁紙を共存させても競合しません。
3. **待機時バッテリー消費ゼロ**: iOS純正レンダラーによる直接ハードウェア描画で、**待機時0%消費**と**60 FPS高リフレッシュレート**を両立。

## 🚀 4ステップ簡単導入ガイド

1. **ファイルをダウンロード**: [公式ストア](https://tendieswallpaper.com/) でお好きな動的壁紙を選び、`.tendies` を取得します。
2. **デバイスを接続**: iPhone / iPadをUSBケーブルでPCまたはMacに接続し、**「このコンピュータを信頼」**をタップします。
3. **Nuggetでインポート**: Nuggetを開き、**PosterBoard** からダウンロードしたファイルを選択して **Apply Changes** をクリックします。
4. **再起動して設定**: 端末の再起動後、ロック画面を長押しして「コレクション」から壁紙を選択します。

> 📖 **公式チュートリアル:** [Nugget PosterBoard 完全インストール手順](https://nugget.host/en/tutorial/nugget)
