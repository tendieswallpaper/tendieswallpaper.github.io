## 💡 What is a `.tendies` File?

A **`.tendies` file** is a proprietary PosterBoard wallpaper bundle format developed for the Nugget customization ecosystem (including Cowabunga and Pocket Poster).

Rather than relying on battery-draining screen-recording overlays or 3-second Live Photos, a `.tendies` file restores directly to Apple's native **PosterBoard** container:
1. **Container Assets**: Injects native wallpaper plists and asset catalogs without modifying system root partitions.
2. **Wallpaper Descriptors**: Uses randomized UUID descriptors to prevent conflicts between multiple dynamic wallpapers.
3. **Hardware Acceleration**: Executes through the native Apple lock screen compositor, guaranteeing **0% idle battery drain** and buttery-smooth **60 FPS** animation.

## 🚀 How to Install in 4 Simple Steps

Installing a `.tendies` dynamic wallpaper takes under 3 minutes using the free, open-source [Nugget](https://nugget.host/) tool:

```
[1. Download .tendies] ──> [2. Connect iPhone via USB] ──> [3. Apply in Nugget] ──> [4. Reboot & Enjoy]
```

1. **Download the File**: Choose your favorite dynamic wallpaper from the [Tendies Wallpaper Store](https://tendieswallpaper.com/) and download the `.tendies` bundle.
2. **Connect Device**: Plug your iPhone or iPad into your PC or Mac via USB and tap **"Trust This Computer"**.
3. **Import via Nugget**: Launch Nugget, navigate to the **PosterBoard** section, select your `.tendies` file, and click **Apply Changes**.
4. **Reboot & Enjoy**: Once your device reboots, long-press the lock screen, tap **Customize**, and select the new dynamic wallpaper under Collections or Favorites.

> 📖 **Read the Official Tutorial:** [Nugget PosterBoard Installation Guide](https://nugget.host/en/tutorial/nugget)
